# CADets notebooks

Course notebooks for Clinical AI Designers. Open them from the course site with the "Open in Colab" button.

- `lessons/<CODE>/` holds each lesson's practice and enrichment notebooks.
- `data/` holds the synthetic course dataset and its data dictionary. Each release is added on the day it is given out.

All data here is synthetic. This repository is public: never add real patient data, solution notebooks or instructor-only files.
